# 자기완결 스니펫 인식 변환 — 설계

- **날짜**: 2026-06-10
- **배경**: v1(AI 인식)은 풍부하지만 비싸고 케이스스터디 누적. v2 절대좌표 덤프는 의미 없는 지오메트리 골격(아이콘 벡터까지 덤프). 두 비교(`Page 1_v1.xml` vs `pageAbsolute.xml`)로 **스니펫 인식 레벨**이 정답임을 확인.
- **배포 목표**: esbuild로 묶어 **zip → 누구나 Figma Import**. 따라서 **런타임 AI 의존 금지(자기완결)**. AI(Claude Code)는 *지금 빌드타임*에 인식 규칙을 짜 넣는 데만 사용.

## 목표
선택한 Figma 프레임을 **스니펫 단위로 인식**해 깔끔한 WebSquare 페이지로 변환한다. 인식은 결정론 휴리스틱이 1차 추측하고, **사람이 UI에서 영역별 타입을 수정**해 정확도를 보장한다(런타임 AI 0).

## 파이프라인
```
선택 프레임
 → ① denoise   아이콘/벡터 서브트리 접기·제거 (g8·g52 같은 노이즈 제거)
 → ② segment   루트 직계(오토레이아웃 단위)를 "영역"으로 분할
 → ③ classify  영역별 스니펫 타입 1차 추측 (이름규칙 + 구조 휴리스틱 + confidence)
 → ④ UI 수정   영역 목록 + 영역별 타입 드롭다운 → 사람이 오인식만 수정
 → ⑤ render    영역→기존 스니펫 변환기로 결정론 렌더 + meta_snippet + sub_contents 조립 + 문서 외피
```
핵심: 인식 틀려도 **사람이 타입 한 번 고치면 끝**(Approach A의 그 한 비트). 마크업은 항상 정확.

## ① Denoise (노이즈 제거)
노이즈로 간주해 접거나 버림:
- `type` ∈ {VECTOR, BOOLEAN_OPERATION, ELLIPSE, STAR, POLYGON, LINE}
- 텍스트 아닌 아주 작은 노드(가로·세로 모두 ≤ 24px 등 임계값)
- 서브트리가 전부 벡터/도형인 컨테이너 → `{kind:"icon"}` 한 토큰으로 접음(셀렉트 셰브론 감지용으로 "아이콘 있음"만 기억)
→ 분류·렌더 입력에서 픽셀 노이즈 제거.

## ② Segment (영역 분할)
- 1차 영역 = **선택 루트의 직계 자식**(오토레이아웃 섹션). 예제: [검색바, 카드행].
- 필요 시 한 단계 더 들어가 하위 영역 분할(예: 카드행 → 카드들).

## ③ Classify (휴리스틱 1차 추측)
신호 우선순위:
1. **레이어 이름 접두사**(있으면 高신뢰): 기존 `classify()`(btn_/inp_/sel_/tbl_/grid_/tab_…) 재사용.
2. **구조 휴리스틱**(이름 없을 때):
   - titbox: 상단의 넓고 낮은(높이 ~32–56) 행, 좌측 라벨 텍스트 (+우측 컨트롤).
   - select: 텍스트 + 우측 셰브론(아이콘) 보유.
   - input: 단일 라인 박스, 셰브론 없음.
   - button: 작은 박스 + 중앙 텍스트 + 채움색.
   - grid/카드: **반복되는 유사 형제** 다수.
   - inputTable: 라벨/값 셀이 표 형태로 반복.
   - tab: 가로로 나열된 탭 라벨 + 활성 표시.
   - text: 단독 텍스트.
   - group: 폴백 컨테이너.
- 각 영역에 `{guessedType, confidence}` 부여. **휴리스틱은 완벽할 필요 없음** — 사람이 ④에서 수정.

## ④ UI (영역별 타입 수정)
```
영역 목록
 ① 검색바 영역   [타이틀 ▾]   (추측: titbox, 신뢰 높음)
 ② 카드행 영역   [그리드 ▾]   (추측: grid, 신뢰 중간)
[페이지 생성]
```
- 각 영역의 추측 타입을 드롭다운으로 노출, 사람이 틀린 것만 변경.
- 낮은 confidence는 시각 강조(확인 유도).

## ⑤ Render & 조립
- 각 영역 → 확정 타입의 **기존 변환기**(title/inputTable/grid/singleInput/button/tab 등)로 깔끔 렌더.
- 슬롯(라벨/컬럼/탭명)은 denoise된 영역의 텍스트에서 결정론 추출.
- 각 영역 루트에 `meta_snippetCategory/Name` 부착, `<xf:group class="sub_contents">`에 순서 조립, 문서 외피(html/head/model/script/body)로 래핑.

## 재사용 / 강등 맵
- **재사용**: 6개 스니펫 변환기, `buildInputTable`/`buildGrid`, tabControl 빌더, `el/serialize`, `extract`, `prettyXml`, 문서 외피, 이름규칙 `classify()`.
- **강등**: 절대좌표 지오메트리 덤프(pageAbsolute)는 "분류 안 됨" 폴백/옵션으로만.
- **신규**: denoise, segment, 구조 휴리스틱 classify, 영역 조립, 영역수정 UI.

## 1차 범위
- denoise + segment(루트 직계) + 이름규칙 우선 분류 + 구조 휴리스틱 일부(titbox/grid/button/text) + 영역 UI + 조립.
- 휴리스틱이 약해도 사람이 수정 가능하므로 **동작하는 자기완결 파이프라인**이 1차 목표.
- 점진: 휴리스틱 정교화(select 셰브론, inputTable, tab), 하위 영역 분할.

## 성공 기준
1. 예제(검색바+카드)를 선택→변환하면 titbox/grid 스니펫 페이지가 나오고, 오인식은 UI에서 수정 가능.
2. 런타임 AI 호출 0. zip Import만으로 동작.
3. 같은 입력+같은 수정 → 같은 출력(결정론).
4. 아이콘 벡터 노이즈가 출력에 안 나옴.
